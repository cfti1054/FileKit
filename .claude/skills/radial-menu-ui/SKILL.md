# 원형 메뉴 화면 구현법

spec 5장을 화면 코드로 옮기는 기준이다. 값은 spec의 수치를 그대로 쓰고 CSS 변수로 한 곳에 모은다.

## 수치

| 요소 | 값 |
| --- | --- |
| 바깥 지름 | 240px (100% 배율 기준, CSS px로 쓰면 WebView가 DPI 배율을 적용) |
| 허브 지름 | 96px |
| 데드존 반지름 | 40px. 여기서 놓으면 취소 |
| 칸 사이 틈 | 4px. 구분선 없음 |
| 칸 수 | 기본 4, 최대 8 |
| 라벨 | 형식 이름 17px 굵게 + 설명 11.5px. `font-family: "Segoe UI Variable", "Malgun Gothic", sans-serif` |
| 안내 줄 | 메뉴 아래 12px, 높이 28px. 화면 아래 끝이면 메뉴 위로 |
| 기본 배치 | 왼쪽 위·오른쪽 위·왼쪽 아래 = 자주 쓰는 형식, 오른쪽 아래 = 더 보기 |

칸은 SVG `path`(도넛 조각)로 그린다. 틈은 각 조각의 시작·끝 각도를 줄여서 만들고, 선을 덧그리지 않는다.

## 상태

- **기본:** 판 배경 + 칸 테두리 1px, 기본 글자색.
- **커서가 있는 칸:** 강조색 12% 채움 + 2px 테두리, 라벨 굵게. 안내 줄 문구가 그 형식 설명으로 바뀐다.
- **사용 불가:** 흐리게(불투명도 낮춤). 고를 수 없고, 커서를 올리면 안내 줄에 이유(예: "LibreOffice가 설치되지 않았습니다").
- **더 보기:** 고르면 바깥에 두 번째 고리를 펼쳐 나머지 형식을 놓는다.
- **여러 파일:** 허브에 "3개 파일". 형식 목록은 Rust 쪽이 공통 형식만 계산해 보낸다. 화면에서 다시 계산하지 않는다.

## 움직임

| 동작 | 시간 | 방식 |
| --- | --- | --- |
| 열기 | 140ms | scale 0.85 → 1, opacity 0 → 1, ease-out |
| 칸 강조 전환 | 80ms | 채움색만 |
| 고르기 | 120ms | 고른 칸이 한 번 진해진 뒤 커서 쪽으로 줄어듦 |
| 닫기(취소) | 100ms | opacity만 |

Windows "애니메이션 효과"가 꺼져 있으면 움직임 없이 바로 나타나고 사라진다. `prefers-reduced-motion: reduce`를 따르고, Rust 쪽이 보내는 설정값이 있으면 그것을 우선한다.

오버레이 창은 숨겼다 다시 쓰므로, 닫을 때 상태(강조 칸, 두 번째 고리, 애니메이션 클래스)를 반드시 초기화한다.

## 테마

- 밝게·어둡게: `prefers-color-scheme`. 어두운 모드는 판을 진한 회색, 라벨을 밝은 색으로.
- 강조색: Rust 쪽이 Windows 강조색을 이벤트로 보내면 `--accent`에 넣는다. 라벨·배경 대비가 4.5:1에 못 미치면 기본 파란색 `#0067C0`(어둡게: `#4CC2FF`)으로 바꾼다. 대비 계산은 WCAG 상대 휘도 공식으로 순수 함수를 만든다.
- 고대비: `@media (forced-colors: active)`에서 흐림·그림자를 끄고 테두리 2px를 시스템 색(`CanvasText`, `Highlight`)으로.
- 판 뒤 반투명 흐림(Acrylic)은 Rust 쪽 `window-vibrancy`가 맡는다. 화면은 배경을 반투명하게만 둔다.

## 조작

- 포인터: 허브 중심 기준 각도와 거리로 칸을 정한다. 거리 < 데드존이면 "없음". 각도 → 칸 번호는 칸 수 N에 대해 일반화한 순수 함수로 만들고 테스트한다(경계 각도, N=4·8, 데드존 경계).
- 클릭 방식: 열린 뒤 이동 → 왼쪽 클릭 또는 휠 클릭으로 고른다.
- 제스처 방식: 휠 버튼을 누른 채 끌었다가 놓으면 놓은 위치의 칸을 고른다. 데드존에서 놓으면 취소.
- 키보드: 숫자 1~8 = 해당 칸, 방향키 = 칸 이동, Enter = 고르기, Esc = 취소. 메뉴 바깥 클릭도 취소.

## 접근성

- 루트 `role="menu"`, 칸 `role="menuitem"`, 사용 불가 칸 `aria-disabled="true"`.
- 열릴 때와 칸이 바뀔 때 낭독 문구를 `aria-live="assertive"` 영역에 쓴다. 예: "변환 메뉴, 발표녹화.mov, MP4 1/4".
- 라벨·배경 대비 4.5:1 이상.

## 테스트

- Vitest: 각도→칸, 대비 계산, 키 입력 → 동작 매핑, 닫을 때 상태 초기화.
- 브라우저에서 `radial.html`을 열면 mock 데이터로 4칸·8칸·여러 파일·사용 불가 상태를 볼 수 있게 한다.
